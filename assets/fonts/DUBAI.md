# Dubai Font

Requested by the owner for the White Swan admin visual refresh on October 22, 2026. Files are self-hosted so viewing private guest data never requires a request to a third-party font CDN.

The private guest companion reuses these same unmodified fonts to match the established admin brand. The public marketing pages retain their existing typography.

Source: the owner's supplied [Dubai Font distribution](https://www.npmjs.com/package/@ahmedhamdan/dubai-font), pinned to version 1.0.0. Original filenames are DubaiW23-Light, DubaiW23-Regular, DubaiW23-Medium and DubaiW23-Bold. The font binaries are unmodified; the local filenames identify weight. Exact source URLs are recorded in SOURCES.json.

Dubai is the Government of Dubai's typeface. The npm wrapper identifies its package license as ISC; this does not relicense the font artwork. Font copyright and embedded notices remain in the original binaries. Existing SIL licenses apply only to the retained Inter and Cormorant files.
